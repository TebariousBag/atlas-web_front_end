# Bootstrap
## Overview
In this project we took our first look at Bootstrap. But only focused on styling given HTML pages and and making responsive pages to recreate the examples we were given.
Bootstrap - is a free and open-source CSS framework directed at responsive, mobile-first front-end web development. It contains CSS and JavaScript design templates for typography, forms, buttons, navigation, and other interface components.
## Learning Bootstrap
I felt like it was difficult to learn going from only learning CSS first. It seemed backwards only styling that way. I felt stuck for a long time because there was so much to learn from the libraries that are there for you. But, affter feeling stuck and stale on making any progress it started to click. I was looking at the whole thing instead of breaking it down little by little.
## Conclusion
I can see how this would be a useful tool to learn, or something else similar along with CSS. But I feel like this would take me quite a bit of time to get down. I think I would like to see what else is available in terms of styling before going too far into Bootstrap.
