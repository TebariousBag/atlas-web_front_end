# Flexbox

## A Layout System
In this project we are learning more about Flexbox. It's a CSS system that helps with laying out your website.

### Overview
I've had some experience with flexbox at this point. But this project helped me understand it a bit more. You create a container to hold the items that will flex. So you tell the container the declarations like show them in a column or a row. Or are they gonna be centered? Where is the main axis? if its a column it's vertical, but if it's row it's horizontal. There are so many ways of manipulating the content, and then you have flex containers within flex containers and you also need to manipulate the items within there as well. It's a very important tool that I need to continue to learn more about.
