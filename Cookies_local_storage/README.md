# Cookies and Local Storage (Max's Version)
## Overview
In this project we learn what cookies are and how to use them. We started with vanilla Javascript creating and getting them. And we also learn to use them with js-cookie library. We also learn the difference between localStorage and sessionStorage.
## Cookie Management
* Setting cookies with custom expiration dates
* Configuring cookie attributes (path, domain, secure flags)
* Reading and deleting existing cookies
* Handling signed cookies for security
## Web Storage
### localStorage
* Persistent storage that survives browser sessions
* Data stored until explicitly cleared
* Accessed via window.localStorage API
### sessionStorage
* Temporary storage lasting only for the current session
* Automatically cleared when browser closes
* Accessed via window.sessionStorage API
