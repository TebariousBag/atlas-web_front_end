# Sass & Scss

## Syntactically Awesome Style Sheets & Sassy CSS
In this project we are learning how to use Sass and Scss for the first time. Some of it I found neat and useful, and other parts I'm not sure about so far.

### Variables
I like being able to declare variables and be able to reuse them at any given time. It creates an easy way to set up font-color, size, etc.. and add those values to any other given section when needed.

### Nesting
I'm not sure if I necessarilly like the nesting. I can't tell if it makes it more confusing rather than just target exactly what you want otherwise.

## Overview
This assignment wasn't that in depth, I'm probably missing alot of the potential it has. But I see some useful things and will probably find more as I continue to learn more.
