# Accessibility

## Introduction

In this project we learn about accesibility for websites. Not everybody views web content, it could be due to a disability or it could be the device used to view the content.

## Aria

Accessible Rich Internet Applications is essentioally a translator that takes the html and communicates them with assisted tecnologies. Depending on how in depth you want to go it could be just making sure there is enough information in your HTML to do things like reading the screen and describing what the person is viewing.

## Levels of Accesibility

There are different levels depending on how much you are putting in your HTML.

Level A (Basic):
* Essential features that prevent major barriers
* Like having alt text for images
* Required minimum level of compliance

Level AA (Recommended):
* More comprehensive coverage
* Includes color contrast requirements
* Most organizations aim for this level

Level AAA (Enhanced):
* Highest level of accessibility
* Very strict criteria
* Often difficult to achieve for all content

## Overview

There are many tools available to help make the web accessible to everyone and it's up to us to help use these tools to make it a place we can all use.
